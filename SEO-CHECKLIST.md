## Owner to-dos (after DNS propagation, ~24h)
1. **Google Search Console** (search.google.com/search-console)
   - Add a Domain property for `trayijewellers.in` (DNS TXT verification).
   - Submit the sitemap: `https://trayijewellers.in/sitemap.xml`.
   - Use "URL Inspection → Request Indexing" for /, /education, /collections.
2. **Google Business Profile** (existing listing: https://maps.app.goo.gl/djxGU258jm4cYURd8)
   - Set the website field to `https://trayijewellers.in`.
   - Primary category: "Jewelry store"; add "Diamond dealer" as secondary if available.
   - Keep name/address/phone EXACTLY matching the website footer.
   - Add fresh photos (storefront, interiors, pieces) and post weekly.
   - Ask happy customers for reviews — reviews naturally mentioning "lab grown diamonds" and "Mangalore" help most.
3. **Bing Webmaster Tools** — import from Search Console, submit the same sitemap.
4. **Consistency & citations** — same NAP on Instagram bio (link to trayijewellers.in), Justdial, IndiaMART, Sulekha, Facebook page.
5. **Expectations** — a new domain typically takes 4–12 weeks to rank for local terms; Business Profile + reviews usually move first.

## Quick health checks (anytime)
- `https://trayijewellers.in/robots.txt` and `/sitemap.xml` load.
- Google Rich Results Test on `/` (JewelryStore), `/education` (FAQ), any product page (Product).
- `site:trayijewellers.in` in Google shows indexed pages growing week over week.
